First, we compiled a vulnerable Linux kernel and set up a super-lightweight virtual machine using QEMU. We had to do

2. The Truncated Kernel Obstacle
When we tried to run the original Python exploit, we encountered an error stating that a file could not be found

3. Plan B (The Bypass)
When we realized that the virtual machine was too small to withstand the actual attack, we had to intervene directly at

#-------------------------------------------------------------------------------------------------------------------

to directly provide us with a console with full control (root). We did this to overcome the lab’s technical limitation,

to manipulate the boot sequence at a low level.
